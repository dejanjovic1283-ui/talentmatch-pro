## Production formats

TalentMatch Pro supports PDF and TXT exports for the main analysis workflows, plus CSV where the workflow requires it. Supported modules include CV Analysis, ATS Checker, CV Rewrite, Semantic Match, Recruiter Mode, and History.

## Privacy rules

Public samples must not contain real personal data, private CV documents, API keys, Firebase private keys, PayPal secrets, or `.env` values. Every new report must pass a content and link review before publication.
